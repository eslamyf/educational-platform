# نَوَى — منصة تعلّم عربية حديثة

نَوَى هي تجربة Frontend كاملة لمنصة عربية لعرض وبيع الكورسات، مبنية بـ React وVite، ومصممة من البداية باتجاه RTL. الفكرة البصرية ليست مكتبة محتوى ضخمة، بل مساحة هادئة تساعد المتعلّم على اتخاذ قرار واضح: ماذا سيتعلم؟ هل يناسبه هذا المسار؟ وما الخطوة التالية؟

> **حالة المشروع:** نسخة Portfolio قابلة للتشغيل ببيانات Mock. تجربة السلة والدفع تفاعلية، لكنها لا تنفّذ تحصيلًا حقيقيًا.

## فكرة المنتج

بدلًا من نسخ نمط Udemy أو Coursera، تستخدم نَوَى لغة تحريرية عربية دافئة: خلفية ورقية كريمية، حبر داكن، أخضر زيتي للثقة، ولمسة مرجانية للحركة. صفحة تفاصيل الكورس هي المركز الحقيقي للتجربة؛ فهي تجمع النتيجة المتوقعة، الملاءمة، المستوى، الثقة، المنهج، التقييمات، المدرّب، والكورسات المقترحة في تسلسل يمكن مسحه سريعًا أو قراءته بعمق.

## UX وقرارات التصميم

- **Course-first:** بطاقة الكورس تلخص التصنيف والمستوى والوقت والتقييم والسعر قبل الدخول.
- **تفاصيل قبل الشراء:** صفحة الكورس تقدم النتائج، لمن يناسب، المتطلبات، المنهج، الدروس المجانية والمقفولة، آراء الطلاب، ومعلومات المدرّب.
- **Curriculum كرحلة:** الوحدات مبنية كـ Accordion مرقّم مع مدة الوحدة، عدد الدروس، وحالة كل محاضرة.
- **لوحة طالب قابلة للتوسّع:** تعرض الكورسات المشترَك بها، نسبة الإنجاز، الدرس القادم، الإيقاع الأسبوعي، وآخر مشاهدة.
- **اكتشاف أدق:** فلاتر متقدمة حسب المستوى، الحد الأقصى للسعر، الحد الأدنى للتقييم، وترتيب النتائج مع بحث نصي وفلاتر التصنيف.
- **قياس الفهم:** Quiz قصير في نهاية المنهج يوضح الإجابة الصحيحة والخاطئة ويسمح بإعادة المحاولة.
- **تجربة مشاهدة داخلية:** Player للمحاضرة، ملفات مرفقة تجريبية، Quiz للمحاضرة، وقائمة منهج قابلة للطي؛ يتطلب فتح الدرس التالي إتمام مشاهدة الدرس والإجابة الصحيحة عن مهمته عند وجودها.
- **حراسة التسجيل:** يمكن تصفح قائمة الكورسات، لكن تفاصيل الكورس والسلة وCheckout وLearning Player تعرض بوابة تسجيل قبل المتابعة. هذا Prototype بصري وليس نظام صلاحيات حقيقي.
- **Thank You motion:** بعد تأكيد الدفع الوهمي تظهر حالة نجاح متحركة مع زر مباشر إلى المسار التعليمي.
- **لوحة مدرس واحد:** إدارة الوحدات والمحاضرات وروابط الفيديو والملفات والاختبارات، مع متابعة تقدّم الطلاب. التعديلات التجريبية تحفظ في `localStorage` وتظهر مباشرة في تجربة الطالب.
- **تسجيل دخول وتسجيل جديد:** نموذج موحّد للطالب والمعلم مع حقول تعليمية مصرية وخيارات الإعدادي والثانوي والبكالوريا المصرية كبيانات UI تجريبية.
- **Light / Dark Mode:** تبديل بصري سريع محفوظ محليًا، بدون تغيير في بنية المحتوى.
- **رحلة واضحة:** Home → Courses → Course Details → Login/Register → Checkout → Student Dashboard → Learning / Video / Lesson.
- **User Flow مرئي:** قسم «كيف تعمل نَوَى؟» أصبح مسارًا تفاعليًا من ست خطوات: إنشاء الحساب، تحديد المرحلة والصف والمسار، اختيار الكورس، مراجعة التفاصيل، الاشتراك والدفع، ثم مشاهدة الدروس ومتابعة التقدم.
- **Multi-Step Registration:** التسجيل مقسّم إلى بيانات الحساب، اختيار المرحلة (إعدادي أو ثانوي) بخيارات صفوف ومسارات ديناميكية، ثم Review نهائي قبل إنشاء الحساب.
- **Validation فوري:** رسائل الخطأ تظهر أسفل الحقل أثناء الإدخال، مع تحقق من البريد وكلمة المرور والهاتف والرقم القومي.
- **Onboarding بعد التسجيل:** شاشة ترحيب تقترح كورسات من الـMock Data بناءً على المرحلة والصف والمسار، مع تثبيت مصر كبلد واختيار المحافظة بدل الدولة.
- **فلاتر المواد:** فلاتر سريعة للمادة في شاشة الترحيب، وفلاتر أكثر اتساقًا في صفحة الكورسات تجمع الصف والمادة والتصنيف والبحث والفلاتر المتقدمة.
- **ملف الطالب:** صفحة مخصصة لتعديل الاسم والبريد والهاتف والمحافظة والمرحلة والصف والمسار، مع تحديث الخيارات الدراسية تلقائيًا عند تغيير المرحلة.
- **صفحة كيف تعمل نَوَى؟:** تجربة مستقلة قابلة للوصول من الـNavbar والـCTA، تحتوي على شرح مبسّط للرحلة وMock Screens تفاعلية لكل خطوة.
- **ثقة بدون ازدحام:** إشارات مثل الوصول مدى الحياة، الشهادة، عدد الطلاب، والدفع الآمن تظهر في مناطق قصيرة.
- **RTL حقيقي:** اتجاه النص والتنقل والأيقونات متسق في Desktop وMobile.
- **لغة قريبة:** النصوص مكتوبة بلهجة عربية مفهومة واحترافية، مع تجنب المصطلحات التسويقية الثقيلة.
- **تحويل هادئ:** لا توجد نوافذ مفاجئة أو Countdown مزعج؛ الإجراء واضح لكن غير عدواني.

## Animations وMicro-interactions

- ظهور متدرج للعناصر عبر `reveal` مع تأخير بسيط لكل بطاقة.
- حركة رفع خفيفة لبطاقات الكورسات مع تكبير محدود للصورة.
- زر التشغيل يتحرك عند Hover بدلًا من إضافة مؤثرات كثيرة.
- Accordion الوحدات يتحرك عبر تغيير الحالة ودوران أيقونة السهم.
- أزرار الإجراءات تستخدم `scale(.97)` عند الضغط وتدرجًا قصيرًا عند Hover.
- Skeleton shimmer معرف في CSS ليستخدم عند ربط API لاحقًا.
- `prefers-reduced-motion` مفعّل لاحترام إعدادات المستخدم.

أفكار الحركة مستلهمة من مبادئ الحركة الهادئة في **Codrops** وعمليات صقل الـ micro-interactions الشائعة في **Dribbble**، لكن التنفيذ والهوية في نَوَى مخصصان للمشروع.

## مصادر الإلهام

- تجارب منصات التعليم العربية والمصرية المذكورة في brief: أحمد الجوهري، خالد صقر، محمود مجدي. تم الاستفادة من وضوح عرض المدرب، السعر، القيمة، وتسلسل المحتوى مع بناء هوية وتجربة مستقلة.

## الصور والـ Assets

- النسخة الأولية تستخدم صورًا مرجعية من [Unsplash](https://unsplash.com/) عبر روابط CDN داخل `src/lib/data.js`.
- أصول بصرية مخصصة لمساحة الـ Hero وبطاقة الكورس مولدة للهوية ويمكن استبدالها بمسارات `/manus-storage/` عند الرفع عبر WebDev.
- صورة مؤسس مخصصة للـHero مولّدة من الصورة المرفوعة مع الحفاظ على الملامح والهوية البصرية العامة.
- لا توجد ملفات صور كبيرة داخل `client/public`، توافقًا مع متطلبات WebDev static.

## Structure المشروع

```text
index.html                  # browser document and metadata
vite.config.js              # Vite, JSX transform, aliases, dev server
package.json                # scripts and dependencies
pnpm-lock.yaml              # pinned dependency graph
src/
  main.jsx                  # browser bootstrap
  app/
    App.jsx                 # application composition
    auth/                   # app-level auth helpers
    errors/                 # error boundary
    providers/              # global state/provider composition
    routing/                # route table
  features/                 # pages and components grouped by product domain
  components/
    common/                 # shared product UI
    integrations/           # external integrations
    layout/                 # shared shells
    ui/                     # Radix/shadcn primitives
  contexts/                 # cross-feature state
  hooks/                    # reusable hooks
  lib/                      # mock data and pure helpers
  shared/                   # values shared with the Express host
  server/                   # optional Express static SPA host
  index.css                 # design tokens and global responsive styles
docs/architecture.md        # dependency boundaries and conventions
```

قواعد الاعتماد بين الطبقات موضحة في [دليل المعمارية](docs/architecture.md). مسارات الصفحات تُسجّل في `src/app/routing/AppRouter.jsx`، بينما تبقى المكوّنات الخاصة بمجال داخل مجلد الـfeature نفسه.

## المكتبات المستخدمة

- React 19
- Vite 7
- JavaScript وJSX
- Wouter للتنقل داخل العميل

- Radix UI / shadcn/ui من القالب الأساسي

## طريقة التشغيل

```bash
pnpm install
pnpm dev
```

لإنشاء نسخة الإنتاج:

```bash
pnpm build
```

يفترض القالب تشغيل Vite على `http://localhost:3000`، مع `--host` لفتح المعاينة داخل بيئة WebDev. يستخدم Vite/esbuild تحويل JSX أثناء التطوير والبناء؛ لا يوجد TypeScript أو أمر `tsc`.

## Mock Data

البيانات موجودة في `src/lib/data.js` وتشمل:

- 7 كورسات عربية ومصرية بمستويات وتصنيفات مختلفة.
- مواد Mock مستوحاة من عناوين ومراحل رسمية: عربي الصف الثالث الإعدادي، أحياء الصف الثالث الثانوي علمي علوم، رياضيات الصف الثاني الثانوي علمي رياضة، وعربي الصف الأول الثانوي، مع شرائح تصفح حسب الصف.
- كورسات مشترَك بها للوحة الطالب مع نسب إنجاز ودرس قادم وملخص إيقاع التعلّم.
- بيانات اختبار تفاعلي مرتبطة بالوحدة الأولى مع حالة إجابة وFeedback وإعادة محاولة.
- المدربين والصور والتقييمات والأسعار القديمة والجديدة.
- الوحدات، المحاضرات المجانية والمقفولة، ومدد الدروس.
- بيانات السلة، Checkout التجريبي، الأسئلة الشائعة، ومحتوى الصفحة الرئيسية.

## ما بعد النسخة التجريبية

هذا الإصدار Prototype بصري فقط: بيانات الدخول، الدفع، تقدم الطالب، وإدارة المحتوى تعمل كحالات واجهة محلية أو Mock ولا تتصل بخادم. لتحويله إلى منتج حقيقي يمكن ربط `Course` و`LearningModule` بواجهة API أو CMS، استبدال تسجيل الدخول بمصادقة حقيقية، تخزين تقدم المشاهدة على الخادم، وربط مزود دفع مصري. الواجهات الحالية مقسّمة بما يكفي لتوسيع هذه الطبقات بدون إعادة تصميم تجربة المستخدم.

## ملاحظة بحثية

استخدمت المنصات العربية المشار إليها لفهم عرض الكورسات والتسعير وإشارات الثقة، مع تجنب تقليد الهوية أو تخطيط صفحة بعينه. الهدف من نَوَى هو تقديم تجربة عربية هادئة، دافئة، ومركّزة على قرار التعلّم نفسه.

لضبط أسماء المراحل والمواد في الـMock Data، تمت مراجعة مصادر وزارة التربية والتعليم المصرية: [المكتبة الإلكترونية والكتب الدراسية](https://studentbooks.moe.gov.eg/)، [النماذج الاسترشادية للصف الثالث الإعدادي](https://moe.gov.eg/ar/prep3/)، و[مجلدات مفاهيم الثانوية العامة](https://moe.gov.eg/ar/openbook-books/). هذه التسميات داخل المشروع لأغراض التصميم والمحاكاة وليست بديلًا عن المنهج الرسمي أو تحديثاته.
